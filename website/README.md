# cecc-linux website

Static Svelte/Vite documentation site for `cecc-linux`, covering installation, CLI/GUI usage, driver notes, troubleshooting, and development workflow.

## Development

```sh
npm install
npm run dev
```

## Checks

```sh
npm run check
npm run build
npm run preview
```

## Deploy

Cloudflare Pages builds from the repo root with:

```sh
cd website
npm run build
```
